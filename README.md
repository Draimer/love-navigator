# love-navigator

戀愛情感導航系統：原有的情感分析流程，以及 24 題依附風格自我探索測驗。

網站：<https://draimer.github.io/love-navigator/>

## 依附風格測驗

從首頁的「依附風格測驗」入口開始。介面沿用粉紅／淡藍主題，支援手機、鍵盤操作、逐題返回、暫回首頁後接續、修改答案、重新作答與複製結果。答案只存於當次頁面的記憶體，重新整理後會清除，不會傳送至 AI 或其他伺服器。

題目為原創自我探索內容，未經心理計量驗證，並非 ECR-R 正式量表、心理診斷或固定人格分類。

計分方式：

- 親密焦慮、親密迴避各 12 題，每題 1–5 分；各有 4 題採反向計分（6 減原始答案）。
- 各面向取平均，再以 `(平均分數 - 1) / 4 × 100` 換算顯示分數；不是機率或百分位。
- 原始平均小於 3 分歸為較低，3 分及以上歸為較高。低／低為安全型，高／低為焦慮型，低／高為逃避型，高／高為混合型（恐懼逃避型）。
- 這個中點是本工具的探索用設定，並非臨床或常模門檻。任一面向平均落在 2.75–3.25 分時，結果會提醒接近分類界線。
- 理論背景：[R. Chris Fraley 的成人依附研究說明](https://labs.psychology.illinois.edu/~rcfraley/measures/ecrr.htm)。四類只是雙軸連續分數的概括，請以分數與實際經驗為主。

## 開發與驗證

靜態網站不需要安裝套件或建置。使用本機 HTTP 伺服器預覽，例如 `python -m http.server 8766`。

執行計分測試（Node.js 18 以上）：

```sh
node --test tests/attachment-quiz.test.cjs
```

主要檔案：`index.html`（入口與頁面切換）、`attachment-quiz.js`（原創題目、計分、互動）、`attachment-quiz.css`（沿用主題的樣式）。`service-worker.js` 已更新快取版本，並預先快取測驗檔案。舊版頁面遇到更新時，請重新整理取得新版本。

發布方式沿用既有 GitHub Pages 設定；將變更合併至發布分支後，確認 GitHub 的 Pages 部署成功。測驗不需要新增後端、金鑰或資料庫。
